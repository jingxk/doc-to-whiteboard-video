# 旁白稿撰写规范

## 核心原则

1. **不照念字幕/原文**：原文是书面语，念出来生硬。要**扩写 + 口语化重写**。
2. **语音必须连续**：观众在静态线稿画面上无法获取信息，一旦语音静默就「断片」。
   因此旁白要**首尾相接铺满全片**，不是按幕平均分配。
3. **字数 = 时长 × 5.8**（晓晓 +30% 语速），宁多勿少。
4. **保留全部关键数据**：原稿的数据、年份、比例、结论一句不落，这是内容价值所在。
5. **先扫多音字再生成**：写完后跑 `polyphone_fix.py --apply`。

## 段落设计

| 项目 | 建议 |
|---|---|
| 段落长度 | 每段 30–55 字（约 6–9s），太长不利于局部重录 |
| 段落数量 | 由总时长决定，不是由幕数决定 |
| 与画面关系 | 不必逐幕对齐；语音连续后画面只是「配图」 |
| 开头 | 首段从 800ms 起（给开场留呼吸） |
| 段间 | 150ms 衔接（人耳几乎无感） |

## 结构模板

```
[开场·定调]     点明主题与重要性（1–2 段）
[问题展开]      逐层展开核心论点（按原文章节顺序）
[数据支撑]      关键数据、案例、对比
[国际参照]      同类现象的他国经验（如有）
[结论推演]      由此得出什么判断
[行动建议]      分阶段/分人群的具体做法
[收尾]          一句话总结
```

## 口语化改写对照

| 书面语（原文） | 口语化（旁白） |
|---|---|
| 人口结构变迁具长期性与不可逆性 | 人口结构，是宏观经济里最确定、最不可逆的慢变量 |
| 代际财富传递机制失效 | 财富没能顺利传到下一代手里 |
| 资产定价逻辑重构 | 资产值多少钱的这套逻辑，正在被重新改写 |
| 配置策略应差异化 | 不同年龄段，配置方式必须彻底分化 |

## 数字读法

edge-tts 对阿拉伯数字读法不稳定，建议：

| 原文 | 改写 |
|---|---|
| 4% | 百分之四 |
| 25% | 百分之二十五 |
| 1990-2015 | 一九九零到二零一五年 |
| 10-15年 | 十到十五年 |
| 50岁以上 | 五十岁以上 |

## narration.json 格式

```json
{
  "meta": {
    "title": "项目名",
    "voice": "zh-CN-XiaoxiaoNeural",
    "rate": "+30%",
    "target_chars": 2285,
    "total_chars_actual": 2268
  },
  "segments": [
    {"id": 1, "scene": 1, "text": "第一段旁白……"},
    {"id": 2, "scene": 1, "text": "第二段旁白……"}
  ]
}
```

`scene` 字段用于追溯与画面的对应关系（可选，不影响音频合成）。

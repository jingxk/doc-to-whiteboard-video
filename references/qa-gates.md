# 质检门禁

交付前必须过检。字幕部分使用 `caption-access-desk` 技能（需另行安装），
音视频部分使用本仓库 `scripts/verify_output.py`。

## 一、字幕质检（caption-access-desk）

### 准备输入

把断句后的字幕时间轴转成 `caption_qa_input.json`（格式见该技能的 `input_template.json`）：

```bash
python <caption-access-desk 技能目录>/caption_engine.py lint \
  --input audio/caption_qa_input.json
```

### 硬性门禁

| 编号 | 指标 | 要求 | 常见失败原因 |
|---|---|---|---|
| F04 | 非语音信息标注 | BGM 必须标注 | `nonspeech[].covered` 未设 true |
| F07 | 最大行数 | ≤2 行 | 整段旁白未断句，堆成 6 行 |
| F08 | 停留时长 | 0.83–7s | 长段一直挂着 / 短句闪烁 |
| W01 | 相邻间隔 | ≥2 帧（0.083s@60fps） | 字幕首尾相接为 0 |

### 达标基线

- **等级 A（≥90 分）、致命 0 项** 才可交付
- 常见不适用告警（单人旁白本地 MP4）：播放器键盘可达性测试、多说话人标识

### 修复顺序

1. 断句到每条 6–26 字 → 消 F07、F08
2. 每条尾部留 100ms → 消 W01
3. BGM 在交付说明中署名 → 消 F04

## 二、音视频自检（verify_output.py）

```bash
python scripts/verify_output.py 成品.mp4 --step 15 --frames 20,60,150,300
```

| 检查项 | 通过标准 |
|---|---|
| 流结构 | h264 视频 + aac 音频 |
| 时长 | 与源视频偏差 <1s |
| 语音连续性 | 静音窗口（<-45dB）不超过采样点的 15% |
| 字幕可见 | 抽帧点底框 >0.5% 且文字 >0.3% |
| BGM | 无人声窗口仍有底噪（不是 -70dB 死寂） |

## 三、人工终检（必做，不可跳过脚本）

1. **听开头 30 秒**：确认音色自然、语速合适、无错读
2. **跳听 3 个中段**：确认无多音字错读、无音量突变
3. **看字幕**：确认大小合适、不遮挡画面主体、切换流畅
4. **看结尾**：确认不是静音收尾

> 脚本只能查「有没有」，查不了「好不好」。音色、断句节奏、字幕观感必须人工过一遍。

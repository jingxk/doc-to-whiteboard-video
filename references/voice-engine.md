# 语音引擎选型与参数

## 引擎对比（实测结论）

| 引擎 | 音质 | 可用性 | 结论 |
|---|---|---|---|
| **edge-tts `zh-CN-XiaoxiaoNeural`** | ★★★★★ 神经网络，有语调/停顿/呼吸感 | 免费、在线、7.3.1 可用 | **首选** |
| macOS `say -v Tingting` | ★★★ 拼接式，偏机械 | 本地、随系统自带 | 兜底（网络不可用时） |
| macOS `say -v Eddy/Flo`（中文大陆） | — | **输出空文件，不可用** | 禁用 |
| macOS `say` 默认语音 | ★★ 机械 | 可用 | 不推荐 |
| 本地 Kokoro-82M 中文 | ★★★★ | 需下载模型 | 备选（离线场景） |

## edge-tts 关键参数

```bash
edge-tts --voice zh-CN-XiaoxiaoNeural --rate=+30% \
         --text "旁白文本" --write-media cue01.mp3
```

- **版本必须 7.3.1**：7.2.8 / 6.1.12 会被微软 GEC 签名校验 403 拒绝
- **语速 `+30%`**：实测 ≈5.8 字/秒，对应「中快」讲解节奏
  - `+0%` ≈ 175 wpm 偏慢
  - 需要更慢/更快时按需 ±10%
- 安装：`pip install edge-tts==7.3.1`
- 常用中文音色：
  - `zh-CN-XiaoxiaoNeural`（女声·温暖·新闻/小说，**推荐**）
  - `zh-CN-YunxiNeural`（男声·解说）
  - `zh-CN-XiaoyiNeural`（女声·活泼）
  - `zh-CN-YunjianNeural`（男声·叙事/纪录片）

## 多音字处理（唯一可靠方案）

**edge-tts 不支持 SSML 注音**——实测 `<phoneme alphabet="sapi" ph="tán xìng">弹性</phoneme>`
会被当作纯文本朗读（同一句时长 1.44s → 4.25s，明显在念标签）。

因此：**在文本层消除歧义**，把多音字替换为语境唯一的写法。

### 常用替换表

| 原词 | 改写 | 说明 |
|---|---|---|
| 增长 | 增速 | 长 zhǎng/cháng |
| 长辈 | 上一辈 | 同上 |
| 长达 | 足有 | 同上 |
| 长期 | 持续 | 同上 |
| 成长 | 扩张 | 同上 |
| 弹性 | 波动 | 弹 tán/dàn |
| 供给 | 供应 | 给 jǐ/gěi |
| 率先 | 抢先 | 率 shuài/lǜ |
| 参照 | 参考 | 参 cān/shēn |
| 顺势而为 | 顺势调整 | 为 wéi/wèi |
| 重估 | 重新评估 | 重 zhòng/chóng |

### 验证方式

用 ASR（AudioTranscribe 工具）转写生成的 mp3，核对是否读成目标词。
注意 ASR 会按语言模型纠错，仅作**辅助**验证，主要靠文本层替换保证。

## 语速与字数换算

```
所需字数 ≈ 视频时长(s) × 5.8    # 晓晓 +30%
```

例：394s 视频 → 约 2285 字旁白。

**宁可多写不要少写**：语音短于视频会造成结尾静音（观众体验差）。
`make_timeline.py` 会在语音总长与目标时长偏差 >8s 时告警。

# 踩坑清单（血泪版，逐条验证过）

按流水线阶段组织。每条都标注了「症状 → 根因 → 正解」，避免重复踩。

## 0. 通用环境

| 症状 | 根因 | 正解 |
|---|---|---|
| `libpython3.13.dylib not loaded` | 技能自带 `.venv` 动态库损坏 | 用自建隔离环境（`python3 -m venv .venv`）或确认可用的系统解释器，别用损坏的 `.venv` |
| `mkdir EEXIST` 报任务失败 | 沙箱对已存在目录 mkdir 报错 | `if not d.exists(): d.mkdir(parents=True)` |
| 后台任务 `nohup ... &` 无输出、产物 48 字节 | nohup 进程被会话回收 | 用工具的 `run_in_background` 跑，不要用 nohup |

## 1. 文档解析

| 症状 | 根因 | 正解 |
|---|---|---|
| PDF 提取出来是「单字一行」 | PDF 排版流式换行 | `extract_doc.py` 已内置中文重组（按句末标点判断续行） |
| 提取内容不全 | 只取了前几页 | 循环全部 pages，别用 `[:N]` 截断 |

## 2. 出图（ImageGen）

| 症状 | 根因 | 正解 |
|---|---|---|
| 并行生成 15 张只得到 8 张 | 时间戳相同导致互相覆盖 | **顺序生成 + 生成后立即 `mv` 固化文件名** |
| 源图带文字 | 提示词未禁文字 | 提示词必须写「绝对禁止任何文字/数字/字母」，生成后逐张复核 |

## 3. 渲染

| 症状 | 根因 | 正解 |
|---|---|---|
| 末帧与源图不重合 | 标注 region 偏移 | 抽查开场/中段/结尾三帧，比对墨迹覆盖率 |

## 4. TTS 语音

| 症状 | 根因 | 正解 |
|---|---|---|
| 语音机械、不自然 | macOS `say` 默认语音是拼接式 | 用 **edge-tts `zh-CN-XiaoxiaoNeural`**（神经网络，最自然） |
| `say -v Eddy/Flo` 输出空文件（0.0115s） | 大陆中文语音包损坏 | 别用；`say` 系列仅 `Tingting` 可用，但音质仍不如 edge-tts |
| edge-tts 报 403 | 版本号被微软 GEC 签名校验拒绝 | **锁定 7.3.1**（7.2.8 / 6.1.12 均不可用） |
| `<phoneme>` 被当文本念（1.44s→4.25s） | edge-tts 不支持 SSML 注音 | **在文本层消除多音字**，见 `voice-engine.md` |
| 语音比字幕窗口长 | 语速估错 | 晓晓 +30% 实际 ≈**5.8 字/秒**（不是 4.95），别按 4.95 过度压缩文本 |
| 改语音后重跑没变化 | 合成脚本跳过已存在的 wav | 改完 TTS 必须确认 mp3/wav 的 mtime，必要时 `--force` |

## 5. 音频合成

| 症状 | 根因 | 正解 |
|---|---|---|
| `Trailing garbage after a filter` | amix 输出后直接链 apad | 拆两条：`...amix=...[voice];[voice]apad=whole_dur=394.000[voice2]` |
| 音轨比视频短 8.3s | amix 默认截断在最后一段语音 | 必须 `apad=whole_dur=<视频总时长>` 补齐 |
| `[err] /bin/sh: 0[v0]: command not found` | filter_complex 字符串被 shell 解析 | 用 Python subprocess 传 list，不要拼 shell 命令 |
| BGM 盖过人声 | BGM 本身响度 -14dB 偏高 | 混音 `volume=0.08`（先 volumedetect 测 BGM 响度再定系数） |
| 幕间几秒静默 | 按幕均分时间轴，幕内语音不够长 | 语音**首尾相接铺满**（`make_timeline.py`），总字数 = 时长 × 5.8 |

## 6. 字幕

| 症状 | 根因 | 正解 |
|---|---|---|
| 「没有字幕」 | mov_text 软字幕很多播放器不显示 | **烧录硬字幕进画面**（PyAV + PIL） |
| ffmpeg 无 `subtitles`/`drawtext` 滤镜 | homebrew 版未编译 libass/freetype | 换 PyAV + PIL 逐帧绘制 |
| 输出视频 0.234fps / duration 102651s | 复用源帧 pts，时间基不匹配 | 写入帧设 `nf.pts = None`，让编码器自动分配 |
| 字幕「偏大」 | 不只是字号——整段 83 字堆成 6 行占屏 38% | 按语义断句，每条 6–26 字渲染 1 行 + 字号 34 |
| 字幕闪烁 | 短句停留 <0.83s | 贪心合并子句到 ≥6 字 |
| 切换生硬 | 相邻字幕间隔 0 帧 | 每条尾部留 100ms 间隔（≥2 帧@60fps） |
| 白板底被误判为「白色文字」 | 暖米黄 #F5EBD7 三通道都 >200 | 检测阈值用 >240，并同时检测「深色底框 <180」 |

## 7. 封装

| 症状 | 根因 | 正解 |
|---|---|---|
| 成品时长比视频短几秒 | `-shortest` 以最短流为准 | 先让音轨 `apad` 补齐到视频时长再封装 |
| 字幕轨显示 394s 截断视频 | 字幕轨略短 | 无碍；内容完整即可，或 `-shortest` 前确认各流时长一致 |
